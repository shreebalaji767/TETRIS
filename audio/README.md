# VOIDBLOCK Music

VOIDBLOCK now supports a full in-game music player.

You can load an audio file with the **LOAD** button. The selected track is played locally in the browser and is not uploaded by the game.

For a soundtrack you are authorized to use, you can also add an audio asset to this folder and wire it as a default track in the game.

Do not commit copyrighted music unless you have permission or an appropriate license to distribute it.
